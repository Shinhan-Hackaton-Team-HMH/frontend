##  🖥️ Project Overview
- 프로젝트 이름: 자영업자도 손쉽게 광고 제작부터 집행, 광고 결과까지 원스톱으로 해결 가능한 서비스 ‘KT 바로광고'
- 프로젝트 목적: KT 바로광고의 기존 원스톱 광고 솔루션을 AI를 활용하여 광고 집행뿐만 아니라 광고 제작 영역까지 지원합니다. 이를 통해 소상공인들의 광고 집행 과정의 진입 장벽을 완화하고, KT바로광고의 새로운 솔루션으로 제안합니다.

##  🖥️ Key Features
1. 광고 업종, 소재 심의 시뮬레이션
    - 사업자등록증·광고 영상 분석으로 업종·소재 적합성 사전 점검
   
2. AI 활용 광고 영상 제작
    -  네이버 지도 가게 링크만 입력하면, 생성된 광고 영상 저장 후 가게 홍보에 재사용 가능

3. 사용자 참여형 광고 QR 
    - QR 기반 인터랙티브 광고: 고객 참여 데이터와 광고 성과 측정 

4. 광고 데이터 리포트 
    - QR 링크 이용자 수 트래킹으로 실시청자 수 정보 제공

## 🧩 Challenges & Solutions

### 1. 소재 가이드 및 업종 제약사항 검증의 복잡성
**Problem**  
광고 소재 가이드라인과 업종별 제약사항이 PDF 문서 형태로만 제공되어  
소상공인이 직접 이해하고 검증하기에 진입 장벽이 높았습니다.

**Solution**  
- **FFmpeg**를 활용해 광고 영상의 규격, 해상도, 용량을 자동 검증  
- **Google Cloud Video Intelligence**를 통해  
  - 객체 인식  
  - 텍스트 추출(OCR)  
  - 유해성 및 부적합 요소 검사  
→ 광고 집행 전 단계에서 소재 적합성을 자동으로 사전 검증하도록 개선했습니다.

---

### 2. 영상 생성 AI의 한계 (퀄리티 · 비용 · 언어 인식)
**Problem**  
기존 영상 생성 AI는  
- 낮은 결과 퀄리티  
- 높은 비용  
- 한국어 문구를 외국어로 오인식하는 문제가 있었습니다.

**Solution**  
- 문구를 제외한 **단일 이미지 기반 영상 생성**  
- 생성된 영상에 대해 **서버 단에서 문구·편집을 후처리**  
→ 영상 퀄리티를 안정화하면서 비용 문제를 해결했습니다.
